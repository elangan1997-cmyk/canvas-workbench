# 精细拆分流程（2026-10-26 本机补丁）

按用户要求补回原版 Skill 更细致的区域决策流程。参考 [LSF 主说明](https://github.com/leishifu666/lsf-image-to-layered-psd/blob/553dba937004eed77609db0bf04242630f325fde/SKILL.md) 与 [PS 流程](https://github.com/leishifu666/lsf-image-to-layered-psd/blob/553dba937004eed77609db0bf04242630f325fde/references/ps-mode.md)，独立实现，不复制原 PSD 组装代码或引入其依赖。

## 使用与实现

画布选图 → 图片拆层 → 拆分方式，默认“精细拆分（推荐）”；另外保留“实用拆分 · 允许原图组合”和“原像素保留”。仅分析可先查看区域制作方案，一键入口继续执行校准、提取、装配和导出。旧任务不自动改策略、不重跑成品。

Agent `canvas_workbench` 传 `split_mode:"detailed"`，HTTP 传 `splitMode:"detailed"`。两者使用同一后端。新字段显式映射 reconstruction/完成策略；未传新字段的旧 API 默认保持兼容。详见插件 AUTOMATION-API.md。

每个精细任务在生成前形成 production-plan.json，并在任务接口/面板提供 productionPlan。分流包含原生文字、原生纯色形状、透明主体、实际有边界的照片、完整背景和明确的原图组合例外。每层保存原图锚点、理由和检查项。

模型输出 frontOf/occludedBy 稳定 ID 关联后，执行器按依赖图修正实际 z 顺序；不是只调整名字或生成顺序。未知引用、自遮挡、背景置顶和循环关系拒绝继续生成；初次模型结构错误可使用已有的有限重试机制修正。关闭已知图层不阻塞其他层。

普通字不会只因简单描边、阴影或斜体就默认合并为整块位图；不支持的效果须记录近似。包装印字随商品，规则底框独立，商品与连续环境分开，实际矩形照片保留场景。保留用户已要求的接触阴影。字体近似替代沿用用户既有选择，不增加逐项确认/安装字体步骤。

这是流程适配，不是原版每项能力的完整复刻：当前尚无任意复杂蒙版/原生渐变/全部文字效果自动重建的保证，不能将全部内容称为可编辑矢量。实用模式仍为独立选项，不把90%当成测得的准确率。
