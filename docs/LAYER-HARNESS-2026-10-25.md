# 拆层 Harness 与 AI 对齐修复验收

日期：2026-10-25；本机补丁，未发布。源码：canvas-workbench；已装副本：desktop npm。全部由Codex完成。

## 根因及实施

已把拆层执行统一为分析→文字校准→结构预检→按类型提取→装配核验→自动导出/展示。UI默认一键PSD，支持AI/SVG及仅分析；运行中不经过会使轮询提前退出的review终态。只对明确的本地临时故障最多重试2次；未知图像请求不自动重发；单层失败继续保存其他成功素材。已有raw本地重建、损坏缓存隔离、导出发布检查点和内容哈希去重均有回归。关闭和刷新恢复原任务及累计额度，仍以所属聊天工作区落盘。

增加typed IR：完整照片(photo)、透明主体(cutout)、原生文字、原生形状、背景。结构预检校正照片直边、邻接分栏及文字胶囊；用户锁定分类/几何优先。完整照片从原图裁出且保持完全不透明，不走抠图；标签底框独立圆角矢量。遮住的标签区域用局部邻域补齐并记录近似，不能宣称恢复不可见真实内容。背景agreement采用平滑权重，避免硬像素块；透明/棋盘格/极端比例及真实质量失败仍拦截。

AI实机定位到ExtendScript条件表达式的原生Justification枚举赋值异常（CENTER变成RIGHT），及字体切换后未刷新导致MRAP。改为显式if分支、最终基线创建点文字、文字内容/字体写入后刷新并取新属性；旋转绕目标基线补偿，移除重复move。分层及普通文字AI共用相同修复逻辑。分层导出保存重开后检查文字、字体、对齐、基线1pt以内及边界变化1pt以内；导出签名加revision避免复用旧错误件。
